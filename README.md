# 🤖 WorkMate AI

WorkMate AI is a full-stack HR Management System built using **FastAPI**, **Angular**, and **SQLite**. It streamlines employee management by providing attendance tracking, leave management, employee profiles, authentication, and HR analytics through a modern REST API and web interface.

## ✨ Features

* Employee Login
* Employee Profile
* Attendance Check-In / Check-Out
* Leave Application
* Leave Approval & Rejection
* HR Dashboard
* REST API with Swagger Documentation
* Angular Frontend
* Conversational AI-ready Architecture

## 🛠️ Tech Stack

## 📡 API Endpoints

* `/login`
* `/profile/{employee_id}`
* `/attendance/checkin/{employee_id}`
* `/attendance/checkout/{employee_id}`
* `/leave/apply`
* `/leave/pending`
* `/leave/approve/{leave_id}`
* `/leave/reject/{leave_id}`
* `/dashboard`
